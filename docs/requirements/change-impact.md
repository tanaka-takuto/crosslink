# 双方向・非方向性の変更検知

## 要求

どの構成ファイルの変更からでも、所属グループ全体の確認が必要であることを検知する。

## 要件

- 変更元と確認対象に、固定の親子関係・依存方向を設けない。
- A・B・Cのどれが変わっても、そのグループ全体を確認対象とする。
- 変更ファイルが直接所属するグループだけを対象とし、共有ファイルを介して他グループへ伝播させない。
- 共有ファイル自体が変更された場合は、そのファイルが所属する各グループを対象とする。

## 受入条件

- A・B・Cをそれぞれ個別に変更した場合、いずれもグループ全体が未確認になる。
- Group-1＝A・B、Group-2＝B・Cが確認済みのとき、Aだけを変更してもGroup-2の確認状態は変わらない。Bも変更した場合は両グループが未確認になる。
