# 変更と確認の区別

## 要求

関連ファイルの編集と、整合性を確認する行為を区別する。
修正不要と判断したファイルは、編集せずに確認を完了できること。

## 要件

- 変更検知後に、他の構成ファイルの編集を必須にしない。
- 構成ファイルの一部または全部を変更しても、確認記録を自動更新しない。
- 必要な修正があれば行い、不要であれば確認だけで解決できる。
- 最後に確認した内容へ戻した場合は、既存記録に基づく[内容に基づく確認状態](confirmation-state.md)の判定に従う。

## 受入条件

- 関連する全ファイルを最後の確認時点と異なる内容に変更しても、編集だけでは確認済みにならない。
- 未変更の関連ファイルに修正が不要な場合、編集せずに明示確認で解決できる。

関連：[明示的な確認操作](explicit-confirmation.md)、[要件一覧](../requirements.md)。
