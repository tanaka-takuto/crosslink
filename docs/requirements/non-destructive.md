# 非破壊的な動作

## 要求

確認対象の内容を勝手に修正せず、検査だけで管理情報を更新しないこと。

## 要件

- 検査や逆引きによって、対象ファイルの内容を自動変更しない。
- 関連性の追加・更新・削除と、確認記録の更新は、対応する明示操作でのみ行う。
- 整合性を取るためのソースコード・文書の自動修正は行わない。
- 検査対象の確認状態を表示するために、確認記録を書き換えない。

## 受入条件

- 検査と逆引きの前後で、対象ファイル、定義、確認記録の内容が変わらない。

関連：[決定性](determinism.md)、[要件一覧](../requirements.md)。
