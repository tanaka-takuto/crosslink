# 変更影響の可視化

## 要求

何が変わり、どのファイルを、なぜ確認する必要があるかを把握できること。

## 要件

- 確認対象のグループ、全構成ファイル、最後の確認時点から変更されたファイル、未変更の確認対象、現在の確認状態を提示する。
- グループに記録した「確認が必要な理由」を提示する。
- ファイルを指定し、直接所属するグループと、そのグループの他の構成ファイルを逆引きできる。
- 人間向け・機械処理向け・AI向けの利用を考慮した結果を提供する。
- 人間向けにはテキストを、機械処理とAIには共通のJSONを提供する。
- ファイル内容の差分表示は不要とする。確認対象を特定できる情報を提供する。

## 受入条件

- A・BのAだけを変更すると、Aを変更ファイル、Bを未変更の確認対象として提示する。
- 変更グループと構成ファイルを特定でき、ファイルからグループ・関連ファイルを逆引きできる。
