# CI/CDとの統合

## 要求

GitHub Actionsなどから非対話で検査し、未確認の変更をマージ条件として検出できること。

## 要件

- CIのチェックアウト先にある実ファイルと、共有された管理ファイルを使って検査できる。
- 未確認や検査不能があれば非ゼロ終了し、CIを失敗させられる。
- 特定の外部サービス、常駐サーバー、ネットワーク接続を実行時に必須としない。
- ツール自体はコミット・ステージ・ブランチ・マージ履歴を判定に利用しない。
- マージ後なども、その時点に存在する内容のハッシュを確認記録と比較して判定する。

## 受入条件

- 必要なファイルを配置したネットワーク不要の非対話環境で、検査を実行できる。
- CI環境に一つでも未確認が残っていれば検査は失敗し、すべて確認済みなら成功する。
