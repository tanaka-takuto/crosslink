# ファイル形式に依存しない

## 要求

ファイルの種類を限定せず、形式専用の機能なしに関連付け・変更検知・確認を行えること。

## 要件

- 拡張子やファイル形式によるホワイトリストを設けず、任意形式のファイルを対象にできる。
- 基本動作に、内容の構文解析や特定の言語・形式を必須としない。
- ファイル内容のハッシュで一致を判定する。

確認記録の保存先として使用するファイルの関連付けは、[グループの要件](groups.md)に従って拒否する。

## 受入条件

- 任意形式のA・Bを、同じ基本操作で関連付けられる。
- バイナリを含むグループでも、内容の変更検知と明示確認が成立する。
- 管理ファイルとしての種別を宣言していない通常JSONは、名前・理由・パス配列が管理定義と似ていても、通常データとして登録・追加・検査できる。

関連：[再現性と決定性](determinism.md)、[要件一覧](../requirements.md)。

詳細仕様：[CLI仕様](../specifications/cli.md)、[保存形式](../specifications/storage.md)。
