# 軽量な導入・運用

## 要求

既存のファイル群へ段階的に導入でき、Gitや常駐サービスなしで利用できること。

## 要件

- すべてのファイルの登録を必須にしない。未登録ファイルは検査対象外とする。
- ツール実行に常駐プロセス、DB、ネットワーク接続を必要としない。
- Gitがなくても利用でき、ステージ・コミットを必要としない。
- プロジェクトの登録や初期化を必須としない。
- 登録グループが0件なら、その旨を通知して成功する。

## 受入条件

- Gitリポジトリではない場所でも、登録したファイルの検査・確認を行える。
- 一部のファイルだけを登録し、未登録ファイルの変更によって確認を要求しない。

関連：[グループ0件](check.md)、[文書への自己適用](../development/documentation.md)、[要件一覧](../requirements.md)。
