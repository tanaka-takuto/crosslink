# 関連性と確認記録の永続化

## 要求

関連定義と現在の確認に必要な記録をファイルへ保存し、他の開発者やAIと共有できること。

## 要件

- グループの定義と確認記録を永続化する。
- 管理ファイルをリポジトリとともにバージョン管理できる。
- 最後に確認した構成・ファイルハッシュの組み合わせを保存し、次回の検査に使える。
- ツール独自の確認履歴を蓄積する機能は不要とする。履歴が必要な場合は利用者がGitなどで管理する。
- 履歴管理にGitを使えることと、CLI実行時にGitが必須でないことを両立する。

## 受入条件

- 確認後にプロセスを終了しても、次回実行時に保存記録から確認状態を再現できる。
- 相対パスで共有した定義・記録・対象ファイルを新しいcloneへ取得し、内容が同じなら同じ判定を再現できる。

関連：[再現性と決定性](determinism.md)、[要件一覧](../requirements.md)。

詳細仕様：[CLI仕様](../specifications/cli.md)、[保存形式](../specifications/storage.md)。
