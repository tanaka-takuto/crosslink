# 再現性と決定性

## 要求

同じ定義、確認記録、実ファイルの内容に対して、同じ検査結果を返すこと。

## 要件

- 内容の一致はファイルハッシュで判定する。
- 更新日時やGitのステージ・コミット状態を判定基準にしない。
- 検査は対象ファイル、定義、確認記録を変更しない。
- グループの定義と現在のファイル内容から判定し、Gitのマージ履歴に依存しない。
- 相対パスの解決基準は、管理ファイルが置かれているディレクトリとする。
- 絶対パスも受け付ける。そのパスに対象が存在しない環境では検査不能とする。

## 受入条件

- 同じ入力で検査を繰り返すと、同じ判定を返し、入力を変更しない。
- ファイル内容と管理情報が同じなら、コミットやステージの有無によって判定は変わらない。
- 管理ファイルと対象ファイルの配置が同じなら、相対パスの参照先がCLIを起動したディレクトリによって変わらない。

詳細仕様：[CLI仕様](../specifications/cli.md)、[保存形式](../specifications/storage.md)。
