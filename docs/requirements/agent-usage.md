# AIエージェントによる利用

## 要求

人間・機械処理・AIエージェントが、それぞれ関連性と変更影響を把握し、同じ基本操作を利用できること。

## 要件

- 参照・検査・確認を対話なしで実行できる。
- 人間とAIに基本的に同じ操作体系を提供する。
- グループ、確認が必要な理由、全構成ファイル、変更ファイル、現在の確認状態を利用できる。
- 自動化に利用できるJSONを、機械処理とAIで共通の出力形式として提供する。
- 通常checkの省略や `-v` / `--verbose` によって、JSONの全グループ・理由・全ファイル・ハッシュ・snapshot・エラーを省略しない。
- JSONの `version: 1` は出力形式の版とし、アプリのversionとは区別する。
- 検査で提示された組み合わせを確認操作へ渡すために必要な情報も、非対話で取得できる。
- CLIの人間向け標準出力はテキストとする。明示した出力先へ保存する[HTMLレポート](html-report.md)も提供する。
- 確認操作をAIが実行できることと、人間により整合性が保証されたことを混同しない。
- 確認できた理由を、AIにだけ追加で要求することもしない。

## 受入条件

- AIエージェントから非対話で関連性・変更影響・確認状態を取得し、確認操作を実行できる。
- 確認操作の成功だけをもって、人間のレビューや意味的な正しさが保証されたと表示しない。
- 機械処理とAIの双方から、同じJSON形式で関連性・変更影響・確認状態を取得できる。
